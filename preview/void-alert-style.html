VOID quiet alerts

A restrained reading surface

提示应该帮助阅读，而不是抢走注意力。

这是 VOID 风格的 Alert 草案：颜色只负责传达类型，留白负责分组，正文仍然属于文章本身。

五种语义，保持同一套节奏

说明

适合补充背景、定义和不会打断阅读的旁注。这里的 NOTE 不需要整块彩色背景。

提示

把一个可执行的小建议放在这里，读者可以顺手完成，不必离开当前上下文。

重要

这是需要读者明确注意的约束，但它仍然使用正常正文颜色，不把整段文字变成警报。

  • 标题表达事实，不制造紧迫感
  • 颜色和图标提供第二重识别

警告

有明确风险时才使用这个类型。代码仍然可以自然地放在提示正文中：

php artisan cache:clear
php artisan config:cache

危险

涉及数据丢失、不可逆操作或安全边界时使用。尽量把动作和后果说清楚。

普通引用仍然是普通引用，不会因为 Alert 的存在而被重新着色。
